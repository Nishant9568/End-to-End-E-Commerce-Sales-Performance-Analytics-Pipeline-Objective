\# 🛒 Olist E-Commerce Performance \& Sales Analytics



\## 📝 Project Overview

This project provides an end-to-end data analytics solution for \*\*Olist\*\*, a Brazilian e-commerce giant. The goal was to analyze over 100,000 anonymized orders to extract actionable business insights regarding sales trends, logistics performance, and customer satisfaction. 



The project involves rigorous data cleaning, complex exploratory data analysis (EDA) using \*\*PostgreSQL\*\*, and the development of an interactive executive dashboard using \*\*Power BI\*\*.

\## 💡 Key Business Insights (SQL \& Power BI)

Through 14 complex SQL queries and visual analysis, the following insights were uncovered:

1\.  \*\*Revenue \& Growth:\*\* Analyzed overall revenue generation and month-over-month sales trends, identifying peak shopping seasons.

2\.  \*\*Category Performance:\*\* Discovered that Health \& Beauty and Bed Bath \& Table were among the top revenue-generating product categories.

3\.  \*\*Logistics \& Geography:\*\* Mapped the highest concentration of orders to the São Paulo (SP) state. Identified average delivery delays and their direct negative correlation with customer review scores.

4\.  \*\*Customer Retention (RFM):\*\* Identified VIP customers using frequency and monetary value metrics.

5\.  \*\*Seller Concentration (Pareto Principle):\*\* Evaluated seller revenue generation to identify platform dependency on top-tier sellers.
